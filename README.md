## Featured Project — Windows Enterprise Diagnostic Toolkit

A PowerShell-based Windows diagnostic and administration toolkit designed to collect system information and generate professional reports.

**Architecture (planned modular design):**

```text
Hardware Engine   → CPU, RAM, GPU, Storage, Battery
Windows Engine    → OS Info, Drivers, Updates, System Health
Network Engine    → Network Info, Wi-Fi, IP Configuration, Connectivity
Security Engine   → Defender, Firewall, BitLocker, TPM, Secure Boot
Report Engine     → Logs, Reports, HTML Dashboard
```

**Status:** In active development. Not all modules are complete — features are being added incrementally as each engine is built and tested.
